# Политика конфиденциальности

Обновлено: 13 апреля 2026

`SalemX` уважает вашу конфиденциальность. Эта политика кратко объясняет, какие данные обрабатываются и зачем.

## 1. Какие данные мы обрабатываем

- Данные аккаунта: Matrix ID, device ID, отображаемое имя, аватар.
- Технические данные: тип устройства, версия ОС/приложения, служебные логи ошибок.
- Данные разрешений: камера, микрофон, фото, уведомления — только при вашем действии и согласии.
- Сообщения и звонки: содержимое обрабатывается через выбранный вами homeserver; для E2EE-чатов содержимое сообщений шифруется на стороне клиента.

## 2. Для чего мы используем данные

- Авторизация и работа аккаунта.
- Доставка сообщений, звонков, уведомлений и синхронизация.
- Безопасность, предотвращение злоупотреблений и улучшение стабильности приложения.

## 3. Передача данных

- Данные передаются вашему Matrix homeserver и необходимым техническим провайдерам для работы сервиса.
- Мы не продаём персональные данные.
- Мы не передаём данные третьим лицам в рекламных целях.

## 4. Хранение данных

- Данные хранятся в течение срока использования сервиса и/или в соответствии с требованиями закона.
- Вы можете удалить аккаунт и локальные данные приложения через настройки или стандартные средства ОС.

## 5. Ваши права

Вы можете запросить доступ, исправление или удаление данных, а также направить вопрос по обработке персональных данных.

## 6. Контакты

По вопросам конфиденциальности: `privacy@wd.mertis.kz`.
